# Security Policy

This repository accompanies an article on [flowki-club.de](https://flowki-club.de) — a German-language community focused on AI/LLM pentesting and security. We take reports of vulnerabilities in this code seriously.

## Reporting a Vulnerability

If you find a security issue in this repository's code (not in flowki-club.de itself — see below), please report it privately:

- Open a [GitHub Security Advisory](../../security/advisories/new) for this repo (preferred — keeps the report private until resolved), or
- Contact us via the FlowKI Club Discord: https://flowki-club.de/join

Please include:
- A description of the issue and its potential impact
- Steps to reproduce
- Affected file(s)/version

## What to expect

- We aim to acknowledge reports within 5 business days.
- This is a community-maintained educational/companion repo, not a production service — response times may vary, but every report gets a reply.
- Please do not open a public issue for security reports; use the private channels above instead.

## Scope

This applies to the code in this repository. For vulnerabilities on flowki-club.de itself, use the same Discord contact — please do not test destructively against the live site without prior coordination.
